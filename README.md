# Bilal Ahmed — DevOps Practice Manual

This repository contains my university DevOps practice work.

## Project overview

A beginner-friendly static website created with HTML as the starting point for learning how source code is stored and managed with Git and GitHub.

## Author

**Bilal Ahmed**

## Project files

- `index.html` — the project home page.

## Run locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Learning objectives

- Create and organize a simple project.
- Track project files with Git.
- Publish source code to GitHub.
- Understand how a static website can be hosted.
